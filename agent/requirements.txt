# The official MCP client. Used for BOTH transports this agent speaks:
# Streamable HTTP to the hosted Infoblox MCP Server, and stdio to the AWS MCP
# server. Bedrock has no MCP connector, so the agent speaks MCP itself.
# Requires Python 3.10+.
#
# The 1.x and 2.x lines differ in ways that break a naive import:
#
#   1.x  streamablehttp_client(url, headers={...})  -> (read, write, get_id)
#   2.x  streamable_http_client(url, *, http_client=...)  -> (read, write)
#
# mcp_client._transport_candidates() finds the factory whatever it is called,
# and _invoke_factory() inspects its signature to pass auth the right way, so
# both lines work. The bound below is deliberately wide; raise the floor only
# if a specific version turns out to be broken.
#
# Verified against 2.x, which is what an unpinned install resolves to today.
mcp>=1.9.0,<3
